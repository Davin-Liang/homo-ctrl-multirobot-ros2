# 4D Artstein 伪速度反馈消融设计

## 目标

在现有 4D Artstein 数值仿真中增加一个消融组，以区分位置预测与真实未来速度预测对延迟补偿性能的作用。

## 固定条件

- 保持现有延迟 plant 不变：命令经纯传输死区和一阶速度响应后更新真实 Follower 状态。
- 保持 Leader 预测、Artstein 历史积分、控制周期、控制器参数和速度限幅不变。
- 不修改真实 plant 状态，也不将速度命令伪装成传感器或里程计数据。

## 新增消融组

新增名称为 `pseudo_velocity_feedback` 的仿真模式。每个控制周期：

1. 按现有 Artstein 反映射和前向预测计算 `x2_pred=[p_pred, v_pred]`；
2. 构造仅供 HPC 反馈使用的状态

```math
x_{fb}=[p_{pred}^T,v_{cmd,prev}^T]^T;
```

3. 将 `x_fb` 而非 `x2_pred` 传入原始 4D HPC；
4. 将 HPC 输出积分为新命令并送入同一延迟 plant。

其中 `v_cmd,prev` 是上一周期经速度限幅后的最终 map 系速度命令。它只是刻意构造的控制器内部伪反馈，不代表真实速度。

## 对照与输出

在现有默认阶跃与圆轨迹工况下，比较：

- 原始 4D HPC + 延迟；
- 完整 4D Artstein 预测补偿；
- 位置预测 + 伪速度反馈。

沿用已有轨迹、距离误差和速度命令图，并在控制台汇总尾段位置误差和最大距离误差。新组的标签必须明确为“pseudo velocity feedback”，不得表述为理想执行器或真实速度反馈。

## 验证条件

- 新模式能运行完成并产生与现有组等长的记录；
- plant 的延迟队列与一阶速度更新仍使用真实 `x2[2:4]`；
- 新组的 HPC 输入位置等于 Artstein 预测位置，速度等于上一周期最终速度命令；
- 原始与完整 Artstein 两组的数值行为不发生改变。
