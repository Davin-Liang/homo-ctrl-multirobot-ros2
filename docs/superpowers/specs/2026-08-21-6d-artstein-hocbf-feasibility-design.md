# 6D Artstein HOCBF 数值可行性设计规格

## 目标

在接入 ROS、Gazebo 或现有避障节点之前，建立一个可重复的离线数值仿真，检验带一阶执行器和常值输入时延的全向跟随者能否使用预测状态上的硬约束 HOCBF-QP 保持与**静态圆形障碍物**的安全距离。

本阶段的结果只说明所定义模型与误差裕度下的数值可行性；不宣称对真实激光遮挡、动态障碍物或实机的绝对安全保证。预测器、HOCBF 定理、离散化缺口和可行性条件见 homo_multirobot_formation_control/doc/6d_artstein_hocbf_theory.md；数值结果必须按该文的“验证—理论主张”映射解释。

## 范围和非目标

### 范围

- 平移平面模型，状态为 `x = [p_x, p_y, v_x, v_y]`，均在 map 坐标系。
- 一阶执行器和常值输入时延：
  \[
  \dot p=v,\qquad \dot v=-v/\tau+u(t-T_d)/\tau.
  \]
- 通过已发布命令历史和该模型，预测到新命令生效时刻的状态。
- 用二阶（指数）控制障碍函数约束静态圆障碍物，并和速度、命令变化率约束共同进入硬约束最小二乘/QP。
- 20 Hz 零阶保持实现与 1 kHz 参考积分的对照；扫描初始距离、名义来向速度、`tau`、`Td` 和延迟失配。
- 当硬约束不可行或模拟感知超时，进入确定性的制动后备，不以安全松弛变量伪造可行性。

### 非目标

- 不修改 `formation_control_node_6d_artstein_disc`、Gazebo、launch 或当前 `ObstacleAvoider`。
- 不建立激光聚类、跨帧目标跟踪或动态障碍物速度估计。
- 不把当前 Artstein/HPC 控制器的全部非线性、目标切换和轮速几何放入第一版证明；名义输入使用可注入的二维速度命令。
- 不在未推导预测误差界前宣称延迟失配下严格前向不变。

## 安全模型

对障碍物中心 `o` 和合并后的安全半径 `R` 定义

\[
h(p)=\|p-o\|^2-R^2.
\]

设预测状态为 `(p_p,v_p)`，对无时延一阶执行器模型，采用

\[
\ddot h + k_1\dot h + k_0h \ge \delta_{rob}.
\]

其中

\[
\dot h=2(p_p-o)^\mathsf{T}v_p,
\]

\[
\ddot h=2v_p^\mathsf{T}v_p +2(p_p-o)^\mathsf{T}(-v_p/\tau+u/\tau).
\]

故每个障碍物给出关于命令 `u` 的仿射硬约束。`R` 必须包含机器人包络半径、障碍物几何半径、定位/感知误差和离散化/预测保守裕度；第一版把它作为显式输入参数，不隐式声称已覆盖未建模误差。

每个控制步求解

\[
\min_u \tfrac12\|u-u_{nom}\|_W^2
\]

满足所有 HOCBF 约束、`\|u\|_\infty\le v_{max}` 和
`\|u-u_{last}\|_\infty\le a_{max}T_s`。若无可行解，后备输出逐步限幅的零速度制动命令，并记录该步为不可行；安全结论仅对约束可行且初始延迟历史安全的轨迹成立。

## 预测与时延

控制器保存过去 `T_d` 区间的实际发布命令，以已知 `tau` 对模型前向积分到 `t+T_d`；HOCBF 在该预测状态而非当前测量状态计算。名义命令可由确定性测试轨迹提供，后续 ROS 阶段才替换成 6D Artstein Disc 输出。

基线仅覆盖 `tau`、`Td` 精确时的模型级安全。延迟失配试验只量化失效边界和所需增大安全半径，不能成为鲁棒安全证明。

## 数值试验与验收

1. **方程/约束单元测试**：解析验证 HOCBF 对 `u` 的仿射系数；安全域内朝障碍物运动会收紧命令上界，远离时不会限制名义命令。
2. **无障碍回归**：输出严格等于限幅后的名义命令。
3. **正面接近**：从安全域内以最大允许来向速度接近静态障碍物；检查 20 Hz 轨迹的最小距离、每步 HOCBF 值、QP 可行性与制动状态。
4. **参数扫描**：扫描 `tau`、`Td`、初始净空和延迟失配，导出 CSV；每一行包含最小 `h`、最小距离、最大命令、HOCBF 最小余量、不可行步数和制动步数。
5. **离散化对照**：同一命令以 1 kHz 参考积分，报告与 20 Hz 轨迹最小安全裕度的差异。

通过条件：准确模型场景中，初始延迟历史安全且 QP 可行的试验没有 `h<0`；无障碍时不修改名义命令；所有不可行情况被显式记录并进入制动后备。若任一准确模型、可行场景出现碰撞，停止 ROS 集成并修正模型或约束。

## 理论边界

标准 HOCBF/CBF-QP 理论支持在控制仿射模型、可行输入集、足够正则性和安全初值下的前向不变性。输入时延需要 predictor feedback；该结论还要求准确预测或将预测误差上界并入鲁棒约束。本规格的离散扫描是验证实现和测量保守度，不代替该证明。
