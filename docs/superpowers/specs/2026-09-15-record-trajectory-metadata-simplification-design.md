# 轨迹记录元数据精简设计

## 目标

移除 `record_trajectory.py` 中与现有信息重复的 `platform` 和
`experiment_id`。未来生成的元数据仅以 `mode` 表示运行环境，实验组通过
目录标签管理，重复次数继续由 `trial_id` 标识。

## 范围

- 删除记录器的两个 ROS 参数、默认值和实例变量。
- 不再在新生成的 `metadata.yaml` 中写入顶层 `platform` 与
  `experiment_id`。
- 同步更新记录器 YAML、README、实验绘图计划和单元测试。
- 不改写已有 `robot_traj` 下的历史元数据或实验数据。

## 兼容性

该变更只影响以后运行记录器生成的元数据。依赖旧字段的外部后处理脚本需自行
从目录名或 `mode` 推断实验分组；仓库内未发现对此字段的读取方。

## 验证

更新记录器 YAML 加载与元数据写入相关测试，确认默认参数集合不含这两个字段，
新生成的 metadata 也不含这两个键；运行对应 Python 测试。
